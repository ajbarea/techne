# phylax

Opt-in Claude Code hooks: refuse attribution lines in commits and PRs, refuse staging COMMITS.md, warn on commits in a main checkout, refuse a subagent call that would silently inherit the session's model, and restart idle sessions onto an updated Claude Code.

```
/plugin marketplace add ajbarea/techne
/plugin install phylax@techne
```

Then run `/phylax:setup`. Install, first use and troubleshooting: [https://ajbarea.github.io/techne/plugins/phylax/](https://ajbarea.github.io/techne/plugins/phylax/). Setup runbook: [AGENTS.md](AGENTS.md).
