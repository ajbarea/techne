# dokimasia

Bibliography verification for LaTeX projects: an offline lint of any .bib or hand-written thebibliography, an online verify against arXiv and Crossref that tells a failed lookup from a wrong entry, and a check that every cited key rendered.

```
/plugin marketplace add ajbarea/techne
/plugin install dokimasia@techne
```

Needs uv. Install, first use and troubleshooting: [https://ajbarea.github.io/techne/plugins/dokimasia/](https://ajbarea.github.io/techne/plugins/dokimasia/).
