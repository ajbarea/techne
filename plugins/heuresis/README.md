# heuresis

Idea triage: capture an idea in plain text, search papers, patents, products and your own work for anything like it, and file it with a verdict grounded in records a script has checked.

```
/plugin marketplace add ajbarea/techne
/plugin install heuresis@techne
```

Needs uv and git; gh is optional. Optional search keys are saved with `/plugin configure heuresis@techne` and kept in Claude Code's secure storage. Install, first use and troubleshooting: [https://ajbarea.github.io/techne/plugins/heuresis/](https://ajbarea.github.io/techne/plugins/heuresis/).
